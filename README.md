## 🛠️ Tech Stack & Architecture

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Styling:** Tailwind CSS v4 & custom design tokens
- **Interactive & 3D:** React 19, Motion (Framer Motion), Three.js & React Three Fiber
- **Icons & Graphics:** Custom inline SVG skill icons, Lucide React
- **Typography:** Geist & Geist Mono
- **Admin Panel:** Built-in protected `/admin` dashboard for dynamic content updates via GitHub API
- **Deployment & Edge:** Vercel edge deployment with apex domain SSL

## 💻 Local Development

### Prerequisites

- Node.js >= 20.x
- pnpm (recommended) or npm / bun

### Getting Started

```bash
# Clone the repository
git clone https://github.com/pyr0ken/portfolio.git
cd portfolio

# Install dependencies
pnpm install

# Start the local development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

### Available Scripts

- `pnpm dev` — Start Next.js development server
- `pnpm build` — Build optimized production bundle
- `pnpm start` — Run the production server locally
- `pnpm check-types` — Run TypeScript type checking
- `pnpm lint` — Run ESLint code checks
